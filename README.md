# Lumiq — AI Data Analysis Platform

> Illuminate your data. Instantly.

Upload any CSV file and get automated EDA,
sentiment analysis, interactive dashboards,
word clouds, AI insights, and a full PDF report.

## Features

- Smart EDA with outlier detection
- 4-model sentiment AI with cross validation
- Interactive Plotly dashboard
- Word cloud generation
- AI-generated plain English insights
- Live text sentiment predictor
- PDF and CSV download
- Dark and light mode

## Tech Stack

Python · Flask · Pandas · Scikit-learn ·
NLTK · VADER · Plotly · WordCloud · FPDF2
